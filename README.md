# Vad.Phoenix

C# private server for Spooky Pop



## Prerequisites

To set up the project, you will need:  
- [.NET 9](https://dotnet.microsoft.com/en-us/download/dotnet/9.0)

## Building the Project
```
git clone https://github.com/Vadimnotdev/Vad.Phoenix.git
```

```
cd Vad.Phoenix/Vad.Phoenix.Server
```

```
dotnet publish "Vad.Phoenix.Server.csproj" -c Release -o app
```

and run Server in app folder

## What is work?
- login
- battle
- database(but you get 50000 score for each completed level)
